# Family Board

A family organisation board: calendar, shopping list, to-dos, meal plan, trips and a message board.
Mobile-first, installable to the home screen, and readable full-screen on a kitchen tablet.

- `docs/`: the web app (plain HTML/CSS/JS, served by GitHub Pages)
- `apps-script/`: the Google Apps Script backend (Google Sheet + Google Calendar)
- [`SETUP.md`](SETUP.md): how to connect it

No family data is stored in this repository.
